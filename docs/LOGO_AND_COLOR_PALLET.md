# Bhagirath Solution - Brand Identity Standards

**Document Purpose:** This guide provides necessary technical and visual standards to define the Bhagirath Solution brand identity. An AI system can use this specification to correctly apply the corporate logo, color palette, and typography across all aspects of the company website.

---

## 1. Master Logo Specification

The logo is the primary identifier. The vector version is the definitive standard.

### 1.1 Logo Description
*   **Type:** Interlocking Monogram (Symbol) + Wordmark (Typography).
*   **The Symbol:** A geometric, abstract visualization of interlocking letters "B" and "S." It is a single, coordinated system of connected, flowing shapes that subtly represents the integrated nature of the solutions provided. It is solid (no outlines), flat (no gradients), and crisp.
*   **The Wordmark:** The exact company name "Bhagirath Solution." It uses a refined, highly legible sans-serif typeface and has strong visual priority over the symbol. It is always presented as sentence case (`Bhagirath Solution`), never misspelled, abbreviated, or all caps.

### 1.2 Logo Composition & Variations
The AI must select the appropriate variation based on the context:

*   **Variation A (Primary):** `[Symbol]` placed directly to the left of the `[Bhagirath Solution]` wordmark. This is the preferred layout for websites (e.g., hero section, navigation bar, footers).
*   **Variation C (Monochrome/B&W):** Used where specific colors are not permissible. The entire logo (symbol and text) is presented in 100% black on a white background, or 100% white on a pure black background.
*   **Variation D (Minimal):** The `[Symbol]` (Geometric "BS") used alone without the wordmark. *Strict restriction: This is only permitted for very small applications, such as a favicon (browser tab) or a social media profile icon, where the company name would be illegible.* The company name must be prominent elsewhere.

### 1.3 Required Exclusion Zone (Padding)
The logo must be surrounded by mandatory negative space (generous whitespace) equal to 50% of the symbol's height on all sides. Do not crowd the logo with other visual or decorative elements.

## 2. Color Palette Specification

The website interface must adhere strictly to these defined color codes for all elements, including background, text, borders, buttons, and graphics.

### 2.1 Primary Brand Colors

| Use Case | Description | Hex Code | RBG Code | HSL Code |
| :--- | :--- | :--- | :--- | :--- |
| **Primary** | Primary Blue: For the main logo structure, all key typography (H1, H2, body copy), and main UI containers. | `#1F293A` | `R: 31, G: 41, B: 58` | `H: 218, S: 30%, L: 17%` |
| **Accent** | Secondary Teal: For the accent element in the logo, primary Call-to-Action (CTA) buttons, link text on hover, and small icon accents (e.g., service cards). | `#20998E` | `R: 32, G: 153, B: 142` | `H: 175, S: 65%, L: 36%` |

### 2.2 Secondary/Neutral Colors

| Use Case | Description | Hex Code | RBG Code | HSL Code |
| :--- | :--- | :--- | :--- | :--- |
| **Background** | Pure White: The universal base color for the website. Generous whitespace is mandatory. | `#FFFFFF` | `R: 255, G: 255, B: 255` | `H: 0, S: 0%, L: 100%` |
| **Light Neutral** | Off-White/Light Gray: (Optional) Used for alternating background sections (e.g., separating sections) or background containers for cards. | `#F8FAFC` | `R: 248, G: 250, B: 252` | `H: 210, S: 20%, L: 98%` |

### 2.3 Strict Restrictions on Color
1.  **No Gradients:** Colors must be flat and solid.
2.  **No New Colors:** Do not introduce random colors that are not defined above.

## 3. Typography Specification

To maintain professional consistency, the typeface family must be clean and highly legible sans-serif.

| Application | Role | Font/Typeface | Weight | Color | Size/Example Use |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Wordmark** | The Company Name (in the logo) | `Modern, Refined Sans-Serif` (e.g., Montserrat, Poppins, Roboto, Inter) | `Semi-Bold (600)` | Blue (#1F293A) | Fixed in Logo Vector |
| **Headings** | H1, H2, H3 | `[Selected Sans-Serif]` | `Bold (700) or Semi-Bold (600)` | Blue (#1F293A) | Largest (e.g., 40px, 32px, 24px) |
| **Body Text** | Paragraphs, lists, and descriptions | `[Selected Sans-Serif]` | `Regular (400)` | Blue (#1F293A) | Highly Readable (e.g., 16px) |
| **Accents** | Labels, button text, links on hover | `[Selected Sans-Serif]` | `Medium (500) or Semi-Bold (600)` | Teal (#20998E) | Small/Medium (e.g., 14px or 16px) |

## 4. Layout and Graphic Rules

To adhere to the "minimalist" brand:

1.  **Whitespace is Mandatory:** Large, deliberate padding must exist around all elements: the logo, headings, text blocks, and sections.
2.  **No Decorative Elements:** Avoid random borders, decorative flourishes, 3D effects, shadows, or tiny fine lines that may break when scaled down.
3.  **Simple Shapes:** Graphic containers (e.g., background boxes) should be simple geometric shapes (e.g., rectangles) with slight, rounded corners, prioritizing cleanliness over stylized flair.
4.  **Vector Icons:** Use simple, flat, vector-style icons. Icons should be Blue, with Teal used sparingly as an accent.

## 5. Website Structure (Summary for Content Context)

*   **Header (Primary):** Site Navigation (Horizontal Logo Variation at the left, nav links at the right). Sticky on scroll.
*   **Hero Section:** Focus on key value proposition. Use large whitespace.
*   **Footer:** Navy Blue background (`#1F293A`). White text. Include Monochrome Logo (White logo on dark blue background). Include quick links and copyright.
